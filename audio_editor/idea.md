- I have audio files, recorded from 2-4 hour long community discussions.
- I need to edit them to cut off periods of long silences (like when people were thinking or waiting before answering a question, there is a long silence before somebody starts speaking. I want to edit these parts out of the audio file).
- Basically, my idea is to have a program which has two parts.
- Part A is to display the audio file in waveform, and allow the user to select and cut portions of the audio. It will be like the Audacity app, but with less functionality. My app needs to show the waveform from an audio file, allow the user to select/cut some parts, and let the user export the edited audio file. Timestamps of the audio must be shown, and there must be play/pause buttons. User must be able to click anywhere on the audio waveform and press Space (or double click) to play/pause the audio.
- Part B is to auto-generate possible silences. When an audio file is imported, there will be an button to auto-detect silences. If it is pressed, the system will analyze the audio track to find periods of low dB. User must be able to set the loudness and time length thresholds to flag a period as possible silences. After system has generated these auto-detections, it must be displayed on the waveform (from Part A). User will inspect each part, and decide whether or not to cut the suggested part, with the click of a button.
- Ideally, that program should run on the web, on the client's browser. If that might be too heavy for the brower, we may consider making it a locally-run app.
